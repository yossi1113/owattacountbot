# owattacountbot
一部で脱AIを頑張りました。
[実際にホストしてます。](https://discord.com/oauth2/authorize?client_id=1491089714533372095&permissions=274877975552&integration_type=0&scope=bot)
<hr>
<h3>機能一覧</h3>
<p>指定した単語に反応</p>
<p>反応した回数を確認</p>
<p>反応しないチャンネルの追加！</p>
<hr>
<h3>ホスト方法</h3>
<p>1. このリポジトリをクローンする</p>

    git clone https://github.com/yossi1113/owattacountbot.git

<p>2. envを追加して編集する</p>
<p>3. ライブラリをインストールする</p>

    cd owattacountbot

    pip install -r requirements.txt

<p>4. コードを実行する</p>

    python main.py

<p>5. 完成！</p>
<hr>
<h3>.envのテンプレート</h3>
<p>リポジトリ内にあるsample.envをコピーして.envに名前変えてつかってね！</p>
